# CoDesign Agent v1.0.2 产品介绍

> **让 AI 不替你思考，而是帮助你把设计想清楚。**

**产品名称**：CoDesign Agent  
**版本**：v1.0.2  
**产品形态**：面向 iPad 的苏格拉底式设计思维训练 Agent  
**核心用户**：设计类学生、创新项目团队、智能产品初学者与课程指导教师

---

## 1. 产品概述

CoDesign Agent 是一款面向设计类与创新类课程开放式项目的 AI 设计澄清工作台。它帮助用户从一个尚未成形的创意出发，在持续对话、可视化推演与主动批注中，逐步形成清晰、可执行、可复盘的产品设计方案。

它不是一个直接生成开题报告的写作工具，也不是要求用户按顺序填写字段的固定表单。CoDesign Agent 更像一位设计思维教练：AI 不急于给出标准答案，而是通过有依据的追问，引导用户澄清目标用户、真实场景、核心痛点、差异化价值、MVP 边界、技术方案、运行规则、验收指标、风险预案与项目排期。

在这一过程中，对话会被持续转化为结构化 Design Brief，问题、回答、判断和方案变化会生长为可交互的思维树。用户既能看到最终结论，也能看见结论是如何形成、为何修改，以及哪些旧方案曾被放弃。

---

## 2. 产品解决的问题

设计项目早期最困难的部分，通常不是“缺少一个完整答案”，而是不知道应该先想清楚什么。常见问题包括：

- 创意描述宽泛，无法对应到明确用户与具体场景；
- 功能不断增加，却没有验证是否真正解决核心痛点；
- 设计讨论散落在聊天和笔记中，缺少结构化沉淀；
- 方案修改后，难以追踪哪些后续判断需要重新检查；
- 课程提交只呈现最终结果，无法展示设计推理与学习过程；
- 在不同设备或不同时间继续项目时，设计上下文容易丢失。

CoDesign Agent 将 AI 对话、设计方法、结构化提取、过程可视化、手写批注与项目归档结合起来，让“思考过程”本身成为可以观察、编辑、保存和继续使用的设计资产。

---

## 3. 核心产品体验

```text
输入模糊创意
→ AI 提供一条恰当线索并提出一个关键问题
→ 用户回答、反思或回到旧节点修正
→ Design Brief 与阶段进度自动更新
→ 思维树记录问题链、判断与分支变化
→ 使用 Apple Pencil 圈画、连线和添加批注
→ 导出 .codesign 项目包
→ 在另一设备或后续时间导入并继续设计
```

CoDesign Agent 以九个设计澄清阶段作为底层专业框架：

1. 痛点与场景锚定
2. 差异化价值提炼
3. 项目边界划定
4. 功能与技术方案拆解
5. 运行逻辑与规则定义
6. 硬性约束设计
7. 量化验收标准制定
8. 风险识别与预案制定
9. 项目阶段拆分与排期

九个阶段提供推荐路径，但不是不可逆的状态机。用户可以回溯和修改前序判断，系统则保留旧分支，并将新的设计结论继续投射到思维树和结构化简报中。

## 4. 四项核心创新

### 4.1 苏格拉底式“隐式三段”提问法则

传统 AI 助手往往过早给出完整方案，使用户跳过定义问题与权衡取舍的过程。CoDesign Agent 的核心不是“代答”，而是“促思”。

系统在每轮对话内部遵循三段式组织逻辑：

1. **线索（Clue）**：帮助用户识别当前设计中的关键缺口；
2. **提问（Question）**：只提出一个足以改变设计判断的开放问题；
3. **依据（Basis）**：从本地设计方法与研究资源中选择相关依据，支撑本轮追问。

这三段不会以机械的“线索 / 追问 / 依据”标题直接展示，而会被融合成自然、简洁的导师式表达。例如：

> 现在比功能数量更关键的，是先确认用户在哪个时刻最需要帮助。如果第一版只能服务一个场景，你会选择哪个具体任务，为什么？

“隐式”设计降低了模板感和认知负担，同时让每次提问仍然具备明确目的与方法依据。系统还会对问题进行资格审查：一个有效问题应当能够推动 Design Brief 字段、阶段状态、思维树节点或学习轨迹发生有意义的变化。

当用户表示“不确定”或“卡住”时，系统不会立刻替用户作答，而是切换到脚手架模式，先提供恰到好处的理解线索，再提出一个可继续思考的问题。

### 4.2 思维树可视化设计过程

CoDesign Agent 将线性的聊天记录转化为一棵可探索的设计推理树。思维树不仅展示“聊了什么”，更展示设计如何演进：

- 项目最初的模糊想法；
- 九个设计阶段及其完成状态；
- 每一轮关键问题、回答与设计判断；
- 从对话中抽取出的 Design Brief 字段；
- 当前正在推进的主线；
- 回溯修改后保留下来的历史分支；
- 设计线索、资源依据与学习动作。

用户可以缩放、拖动思维树，展开阶段内的问题链，并点击节点查看细节。旧答案不会被简单覆盖，而是作为设计演进的证据保留下来。这样，用户能够回答三个重要问题：当前方案是什么、方案为什么变成这样、曾经还有哪些可能性。

思维树也使课程评价从“只看结果”转向“同时看过程”。教师或团队成员可以据此观察问题定义、范围收敛、风险判断与方案迭代是否真正发生。

### 4.3 `.codesign` 项目包：重建设计现场并继续流程

PDF 或 Markdown 适合阅读和提交，但只能保存静态结果。CoDesign Agent 提供专属的 `.codesign` 交互项目包，用于保存可重新打开的设计工作现场。

项目包可包含：

- 项目基础信息与阶段状态；
- 结构化 Design Brief；
- 思维树节点与父子关系；
- 当前主线与历史回溯分支；
- 设计决策路径和学习轨迹；
- 资源线索与引用信息；
- 思维树手写笔迹和文本批注。

用户可以从首页导入 `.codesign` 文件，先进行只读预览，再将其导入为一个新项目。导入后，应用会重建阶段、Brief、思维节点、批注等项目上下文，使用户能够在原有成果上继续对话、修正判断和推进设计。

这使 `.codesign` 不只是“导出格式”，而是 CoDesign Agent 的设计过程载体：

```text
保存现场 → 分享或迁移 → 重建项目 → 继续设计
```

项目以“导入为新项目”的方式恢复，既避免覆盖本机原项目，也便于保留不同版本的设计演进记录。

### 4.4 Apple Pencil 与 iPad 原生设计场景

v1.0.2 面向 iPad 的深度思考、课堂讨论与工作坊场景强化了 Apple Pencil 体验。用户可以直接在思维树上进入批注模式，使用 Apple Pencil：

- 圈出关键问题或风险节点；
- 在不同判断之间补充手绘连线；
- 标记需要回看的设计分支；
- 写下课堂反馈、灵感与待验证假设；
- 配合可移动的文本批注补充说明。

批注画布基于 PencilKit，支持系统绘图工具、撤销、重做与清空，并可选择仅允许 Apple Pencil 输入，避免浏览思维树时的手指拖动与书写操作相互干扰。笔迹与文本批注保存在项目中，也可以随 `.codesign` 项目包一同迁移和恢复。

iPad 横屏下，思维树与当前澄清任务可以并排呈现；竖屏和较窄尺寸则通过分层面板保持内容聚焦。这样的布局让用户能够一边与 AI 对话，一边像在纸上评图一样圈画、连接和修正自己的设计过程。

## 5. 主要功能

### 5.1 自然对话与动态澄清

- 围绕当前最关键的设计缺口持续追问；
- 每轮聚焦一个可回答、可推进的问题；
- 支持“我还不确定”“换个角度问”“给我一个例子”等脚手架操作；
- 支持回到前序判断进行修改，而不是强制线性完成；
- 支持 Mock 离线模式与 OpenAI-compatible Live 模式。

### 5.2 结构化 Design Brief

系统从自然语言对话中持续抽取并更新：

- 目标用户、核心痛点与使用场景；
- 核心价值与差异化；
- 项目边界与 MVP 功能；
- 技术模块、交互流程与运行逻辑；
- 硬性约束；
- 验收指标及测量方式；
- 风险、影响与缓解策略；
- 里程碑与阶段计划。

用户可以查看、编辑、确认或标记字段不准确，使最终简报成为“AI 提取 + 用户校准”的协作成果。

### 5.3 资源线索与设计方法脚手架

应用内置 Persona、用户旅程、5 Whys、How Might We、MVP、假设映射、预演失败、可用性测试等设计方法资源。系统根据阶段、字段缺口和用户回答选择相关线索，作为追问依据，而不是把方法论堆叠到用户面前。

### 5.4 学习轨迹与成果表达

- 记录问题锚定、价值提炼、范围收敛、指标制定与风险识别等思维动作；
- 通过成果看板查看成熟度、MVP 边界、风险矩阵与设计演进；
- 通过作品档案整理设计旅程、证据墙、Brief 海报与反思总结；
- 支持 PDF、Markdown、JSON 与 `.codesign` 多格式导出。

### 5.5 本地优先与多尺寸适配

- 使用 SwiftData 保存项目、对话、结构化字段与批注；
- 默认 Mock 模式无需 API Key，可用于课堂演示和离线体验；
- Live 模式可连接兼容 OpenAI Chat Completions 的模型服务；
- 工作台适配 iPad 横竖屏、iPhone 窄屏与 macOS 宽屏。

## 6. 典型应用场景

### 课程开题与过程性学习

学生从一句模糊创意开始，在 AI 追问中完成问题定义和方案收敛；教师通过思维树、学习轨迹与批注查看其思考证据，而不只评阅最终文档。

### iPad 课堂评图

学生在 iPad 上打开项目思维树，教师使用 Apple Pencil 圈出逻辑断点、风险节点或待验证假设。批注随项目保存，课后可继续转化为新的澄清任务。

### 创新工作坊与团队讨论

团队投射思维树共同回看方案路径，在关键分支上做手写标记，讨论后由一名成员继续与 Agent 对话并更新 Design Brief。

### 跨设备归档与继续设计

用户将当前项目导出为 `.codesign` 文件，在另一设备导入为新项目，恢复设计结构、思维分支和批注，再从原有上下文继续推进。

### 作品集与项目复盘

项目完成后，用户可以导出适合提交的静态报告，同时保留 `.codesign` 交互项目包，完整保存从模糊想法到可执行方案的设计证据。

## 7. 产品价值

### 对学生

- 学会提出和回答真正影响设计判断的问题；
- 看见自己的思维路径，而不只是获得 AI 生成的结果；
- 将零散讨论沉淀为结构化、可提交的项目方案；
- 用 iPad 与 Apple Pencil 保留更自然的个人思考痕迹。

### 对教师

- 查看学生的问题定义、权衡与迭代过程；
- 通过思维树和批注提供更具上下文的指导；
- 区分“生成了一份文档”与“完成了一次设计思考”。

### 对项目团队

- 建立共享的设计上下文与判断依据；
- 在修改前序结论时保留历史分支，减少决策失忆；
- 通过 `.codesign` 项目包归档、迁移和延续完整设计流程。

---

## 8. v1.0.2 的产品主张

CoDesign Agent v1.0.2 将 AI 对话从“答案生成”转向“思维促进”，将聊天记录从“信息流水”转化为“设计推理树”，并通过 Apple Pencil 与 `.codesign` 项目包把设计过程变成可批注、可迁移、可重建、可继续的数字工作现场。

它所交付的不只是一份 Design Brief，而是一条能够被看见和复盘的设计路径：

> **每一个问题都有目的，每一次修改都有分支，每一段思考都可以被继续。**
