# v0.4 思维发散树（Thinking Tree）

## 概述

新增"思维树"可视化界面，与工作台并行作为 ProjectDetail 的一个新 Tab。以径向树的形式展示用户设计思维的展开过程：项目想法为根节点，9 个设计阶段环绕分布，已填充的 Brief 字段作为叶片向外生长，未探索的区域以虚线幽灵节点呈现。

## 树的视觉结构

```
                     [项目想法]                    ← 中心根节点（渐变圆）
                  /  / | | \  \
           [1] [2] [3] [4] [5] ... [9]             ← 环形 9 阶段节点
          /|\   /\   |   /\                        ← 每阶段扇形展开
        [F][F][F] [F][F] [F] [F][F]                ← 已填充的字段叶片
```

- 绿色 = 已完成，蓝紫色 + 光晕 = 进行中，灰色虚线 = 未探索
- 下一个阶段显示 ghost 节点（虚线轮廓），暗示"即将探索的领域"
- 节点大小随 richness 值变化（内容丰富度）

## 新增文件

### 数据层

| 文件 | 说明 |
|------|------|
| `Models/ThinkingMoment.swift` | SwiftData @Model，记录每次思维事件。字段：`momType`（seed/branch/deepen/converge/abandon/revise）、`content`、`stageOrder`、`relatedField`、`parentMomentID`、`timestamp` |

### 视图层（`Views/MindTree/`）

| 文件 | 说明 |
|------|------|
| `TreeModels.swift` | 纯值类型：`TreeNode`（节点）、`TreeEdge`（连线）、`TreeData`（完整树数据）、`TreeBuilder`（从 Project 构建树，读取 BriefField 填充状态和 ProgressStage 状态） |
| `TreeLayoutEngine.swift` | 径向布局算法：root 在中心，9 个 stage 环形分布（半径 170pt），field 节点向外扇形展开（半径 310pt，±24° 扇区） |
| `ThinkingTreeView.swift` | 主视图。Canvas 绘制 Bezier 曲线连线 + 装饰光晕，overlay 渲染交互节点。支持捏合缩放（0.3x–2.5x）、拖动平移、阶段筛选 chips、自动适配视口 |
| `TreeNodeView.swift` | 节点渲染。root：72pt 渐变圆；stage：48pt 状态色圆（编号+名称）；field：胶囊标签（字段名+值预览）。ghost 节点虚线描边+低透明度 |
| `ThinkingNodeDetailSheet.swift` | 点击节点弹出 bottom sheet。root 显示项目统计，stage 显示描述+字段列表+引导问题，field 显示提取值，附带相关学习轨迹 |
| `TreeLegendView.swift` | 右下角可折叠图例：颜色含义 + 手势提示 |

### `Factories/MockDataFactory.swift`

- 在 LearningTrace 种子数据后新增 ThinkingMoment 种子数据链：
  - 1 个 root seed（项目想法诞生）
  - Stage 1：1 branch + 3 deepen（targetUser, painPoint, useScenario）
  - Stage 2：1 branch + 2 deepen（coreValue, differentiation）
  - Stage 3：1 converge + 1 deepen（boundaryItems）
  - Stage 4：1 branch + 2 deepen（mvpFeatures, technicalModules）

## 交互方式

| 操作 | 效果 |
|------|------|
| 捏合缩放 | 0.3x ~ 2.5x 缩放整棵树 |
| 拖动平移 | 自由平移树的位置 |
| 点击节点 | 弹出详情 sheet（medium/large 两档高度） |
| 顶部阶段 chips | 筛选聚焦单个阶段，其他节点淡出 |
| 对话发送消息 | 提取到新字段时树自动长出新节点 |

## 验证步骤

1. 编译：`xcodebuild -scheme CoDesign-Agent -destination 'platform=iOS Simulator,id=7E83E99D-AA67-488D-B2CC-F1F1DF77EAF8' build`
2. 首次运行前删除模拟器上的旧 app（Schema 新增了 ThinkingMoment）
3. 打开 demo 项目 → 点击顶部"思维树"按钮
4. 验证：9 阶段环形分布、已完成阶段（1-3）有绿色字段叶片、stage 4 蓝紫色、5-9 灰色虚线
5. 验证交互：缩放、平移、点击节点、阶段筛选
6. 验证生长：回工作台发消息触发新字段提取 → 思维树长出新节点
