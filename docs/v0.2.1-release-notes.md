## 核心成果

### 1. API 配置泛化与多 Provider 支持

**目标**: 从 DeepSeek 专用配置改为通用 OpenAI-compatible API 支持

#### 环境变量重命名

| 旧名称 | 新名称 | 说明 |
|--------|--------|------|
| `DEEPSEEK_API_KEY` | `LLM_API_KEY` | API 密钥 |
| `DEEPSEEK_BASE_URL` | `LLM_BASE_URL` | API 基础 URL |
| `DEEPSEEK_MODEL` | `LLM_MODEL` | 模型名称 |
| - | `LLM_THINKING_TYPE` | 推理模式控制（新增） |

**读取优先级**:
1. `LLM_*` 环境变量（优先）
2. `DEEPSEEK_*` 环境变量（兼容旧配置）
3. 默认值

#### Thinking 参数可配置化

- 新增 `LLM_THINKING_TYPE` 环境变量
- 支持值：`disabled` / `enabled` / 不配置
- DeepSeek 推荐：`disabled`（关闭 thinking mode，提升稳定性）
- 其他 OpenAI-compatible API：可不配置

**修改文件**:
- `CoDesign-Agent/Services/API/LLMAPIConfig.swift`
- `CoDesign-Agent/Services/API/LLMAPIClient.swift`
- `docs/v0.2-spec.md`（文档更新）

### 2. 真实 Live API 端到端验证

**测试环境**: 百炼大模型（DashScope）

#### 配置示例

```bash
LLM_API_KEY=sk-你的百炼密钥
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL=qwen-max
```

#### 测试结果

✅ **Case 1: 真实 key + live mode**
- 流式对话正常，逐字输出
- JSON 提取成功，DesignBrief 自动更新
- Progress 和 Insights 正常更新
- 无 fallback 日志

#### 问题排查

**问题**: 初始测试时 Live 模式返回 Mock 回复  
**原因**: 模拟器 App 没有网络权限  
**解决**: 在 Xcode 中启用 App Sandbox → Network → Outgoing Connections

### 3. 轻量级 API 设置页

**目标**: 提供 App 内置配置界面，无需修改 Xcode Scheme

#### 功能特性

| 字段 | 类型 | UserDefaults Key | 说明 |
|------|------|------------------|------|
| Service Mode | Picker | `serviceMode` | Mock / Live 切换 |
| API Key | SecureField | `llmAPIKey` | 密码输入框 |
| Base URL | TextField | `llmBaseURL` | API 地址 |
| Model | TextField | `llmModel` | 模型名称 |
| Thinking Type | Picker | `llmThinkingType` | 不发送/disabled/enabled |

#### 配置优先级

1. UserDefaults（设置页输入）- 最高优先级
2. LLM_* 环境变量
3. DEEPSEEK_* 环境变量（兼容）
4. 默认值

#### UI 入口

- **iOS**: 项目列表页左上角齿轮图标
- **macOS**: 项目列表页右上角齿轮图标（与 + 按钮并列）

#### 预设配置示例

**百炼（DashScope）**:
```

Model: qwen-plus / qwen-turbo / qwen-max
Thinking Type: 不发送
```

**DeepSeek**:
```
Base URL: https://api.deepseek.com
Model: deepseek-v4-flash
Thinking Type: disabled
```

**新增文件**:

### 4. UI/交互优化

#### 4.1 设置页示例折叠

**问题**: 设置页预设配置示例默认展开，占用过多空间

**解决**: 使用 `DisclosureGroup` 实现默认折叠
```swift
DisclosureGroup("点击查看配置示例") {
    // 百炼和 DeepSeek 配置示例
}
```

**修改文件**: `CoDesign-Agent/Views/Settings/APISettingsView.swift`

---

#### 4.2 AI 回复 Markdown 渲染

**问题**: AI 回复中的 `**粗体**` 显示为原始符号，未渲染

**解决**: 使用 `AttributedString(markdown:)` 解析
```swift
if message.role == "assistant",
   let attributed = try? AttributedString(markdown: message.content) {
    Text(attributed)
} else {
    Text(message.content)
}
```

**应用范围**:
- `MessageBubble.swift`: 已保存的 AI 消息
- `ChatPanel.swift`: 流式输出的实时文本

**修改文件**:
- `CoDesign-Agent/Views/Components/MessageBubble.swift`
- `CoDesign-Agent/Views/ProjectDetail/ChatPanel.swift`

---

#### 4.3 聊天输入框键盘行为

**问题**: 按 Enter 全选输入内容，无法发送消息

**解决**: 添加 `.onSubmit` 修饰符
```swift
TextField("输入你的想法...", text: $inputText, axis: .vertical)
    .onSubmit {
        if canSend {
            sendMessage()
        }
    }
```

**行为**:
- **Enter**: 发送消息（如果输入非空）
- **Shift + Enter**: 换行（`axis: .vertical` 原生支持）
- 发送按钮点击：保持原有逻辑

**修改文件**: `CoDesign-Agent/Views/ProjectDetail/ChatPanel.swift`

## 技术细节

### 编译问题修复

#### 问题 1: macOS 平台 API 不兼容

**错误**:
```
Value of type 'some View' has no member 'textInputAutocapitalization'
Value of type 'some View' has no member 'keyboardType'
```

**原因**: 这些修饰符是 iOS-only API

**解决**: 移除 iOS 专属修饰符，使用跨平台 API
```swift
// 移除
.textInputAutocapitalization(.never)
.keyboardType(.URL)
```

---

#### 问题 2: macOS 上设置按钮不可见

**问题**: 设置按钮包裹在 `#if os(iOS)` 中，macOS 上不显示

**解决**: 
- iOS: 左上角 `navigationBarLeading`
- macOS: 右上角 `primaryAction`（与 + 按钮并列）

```swift
ToolbarItem(placement: .primaryAction) {
    Button { showingSettings = true } label: {
        Image(systemName: "gearshape")
    }
}
```

## 使用指南

### 首次配置 API

1. 启动 App
2. 点击项目列表页的齿轮图标 ⚙️
3. 选择服务模式为 "Live（真实 API）"
4. 填入 API 配置：
   - **百炼用户**:
     - API Key: `sk-你的百炼密钥`
     - Base URL: `https://dashscope.aliyuncs.com/compatible-mode/v1`
     - Model: `qwen-max`
     - Thinking Type: 不发送
   - **DeepSeek 用户**:
     - API Key: `sk-你的 DeepSeek 密钥`
     - Base URL: `https://api.deepseek.com`
     - Model: `deepseek-v4-flash`
     - Thinking Type: disabled
5. 点击"完成"保存配置
6. 新建项目，开始对话

### 切换 Mock/Live 模式

- 在设置页的"服务模式"区域切换
- 无需重启 App，立即生效

### 清除配置

- 在设置页底部点击"清除 API 配置"
- 会弹出确认对话框
- 清除后恢复为 Mock 模式

## 已知限制

1. **API Key 安全**: 使用 `@AppStorage` 明文存储，后续版本考虑 Keychain
2. **Markdown 支持**: 仅支持粗体（`**text**`），其他 Markdown 语法待验证
3. **多模型切换**: 不支持在对话中动态切换模型，需重新配置
